# Native HTML · 自检清单

模板被移除后,这份清单是 Native 形态的质量地板。它只查**普适的去 AI slop 与工艺底线** —— 不规定美学(冷暖、衬线/无衬线、纸感/深色是 `native-html.md` 第一步认定的方向)。生成后逐项核对,**P0 必须全过**。

## P0 · 不过 = 立刻打回重做

- [ ] 不用纯白 `#fff` / 纯黑 `#000`(暖偏移或冷偏移都行,但不是纯的;深色方向底用 `#0f0f0f` 不 `#000`)。
- [ ] 全文只有一个 accent;层级是用字体 / 字号 / 留白做出来的,不是靠多色。
- [ ] accent 不是默认靛蓝(`#6366f1` / `#4f46e5` 一族)—— 这是头号 AI tell。
- [ ] 一种语言一种字体家族,标题不裸用 `system-ui`;没有 700+ 的笨重标题。
- [ ] 不是 dashboard —— 没有 KPI 卡墙、没有图标堆、没有 hero 渐变。
- [ ] 没有「圆角卡片 + 左侧彩色 border」这种 AI 仪表盘块。
- [ ] emoji 不当图标用(改 1.6–1.8px 单线 SVG)。
- [ ] 没有外链图片 / 占位图 CDN;占位图是色块 + 1px 描边。
- [ ] 没有 drop-shadow / blur / 渐变(阴影顶多是 `0 0 0 1px` 的 hairline 描边)。
- [ ] 没有编造数据(「快 10 倍」「99.9%」);未知值写 `—`,示例数据标注为样例。
- [ ] 没有填充文案(lorem ipsum、「要点一二三」)—— 空白用构图解决,不靠编字填满。
- [ ] **没有照抄范型** —— 配色和字体是为这份产物认定的方向,不是某份 `native-examples/` 的复制品。
- [ ] 文档类型结构完整(如 Long Doc 有封面 / TOC / 章节 / colophon)。
- [ ] 1920px 屏幕上,主容器两侧总留白 ≤ 屏宽 35%(详见 `craft/structure-and-style.md`)。

## P1 · 质量

- [ ] ALL CAPS 字距 ≥ 0.06em;Display(≥48px)用负字距。
- [ ] accent 一屏 ≤ 2 处可见(链接、hover 都算)。
- [ ] 正文对比度 ≥ 4.5:1、大字(>18px)≥ 3:1。
- [ ] 字号 ≤ 6–8 档;行高分档(标题 1.0–1.2、正文 1.5–1.6);不 `justify`。
- [ ] **散文段落**每行 50–75 字(走 measure);**数据 / 表格 / 图表容器**不受此限(走 canvas)。详见 `craft/structure-and-style.md`。
- [ ] **Navigation 决策对了**:章节 ≥ 4 / 技术文档 / 用户提目录时,确实用了 sticky TOC(Branching);否则单列(Linear)。见 `craft/structure-and-style.md` Navigation 决策树。
- [ ] rule 是 1px hairline,长度受控、不到边。
- [ ] 中英文之间有盘古之白。
- [ ] 单文件自包含、双击即开(见 `SKILL.md` 第三步工程约束)。
- [ ] **灵魂检验**:把成品截图给项目外的人看,认得出这是哪一份具体产物 —— 认不出 = 还是模板。
