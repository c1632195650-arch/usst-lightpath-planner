# OSM 校园原始数据

上海理工大学各校区的 OpenStreetMap 原始数据（XML），由 `scripts/fetch_osm.py` 自动拉取。

## 许可（重要）

数据 © OpenStreetMap contributors，遵循 **ODbL 1.0**（Open Database License）。

- ✅ 可自由使用、复制、分发、修改 —— **允许存储**
- ⚠️ 需**署名**：注明数据来自 OpenStreetMap contributors
- ⚠️ 若对外分发本数据、或由其派生的数据库，需以**同样许可（ODbL）**发布

> 因此：若 `campus_map.json` 中出现源自本目录的内容，应先与手工采集部分**分开标注**，
> 并保留上述署名。学生项目无碍，但标注不能省。

对比：高德开放平台的服务条款**禁止存储**其 API 返回数据 —— OSM 没有这条限制，
这是选它的首要原因。

## 覆盖情况（2026-09-11 实测）

- **军工路主校区覆盖最好**：107 栋具名建筑，路网图 1269 节点 / 1433 路段，
  最大连通块占 **89%** —— 足以支撑任意两点的步行路径计算
- **基础学院、复兴路校区**：只有建筑轮廓，**几乎没有名字**，路网也稀疏，目前价值有限
- **营口路校区、军工路 580 号**：OSM 未收录
- **OSM 缺少的**（需手工图谱补齐）：「第一食堂」「思餐厅」「图文信息中心」「国合楼」
  「综合楼」「校史馆」「菜鸟驿站」等 —— 两者是**互补**关系，不是替代

OSM 独有、手工图谱此前缺失的：南一~南十宿舍、清真餐厅、第四教学楼、外语学院、
理学院、教工宿舍、第五学生公寓 1–4 号楼、刘湛恩故居、各国文化交流中心等。

## 更新

```bash
python scripts/fetch_osm.py           # 已存在则跳过
python scripts/fetch_osm.py --force   # 强制重新拉取
```

数据源为 OSM 官方 map API（`api.openstreetmap.org/api/0.6/map`）。
注意 bbox 顺序是 **W,S,E,N**，与 Overpass API 的 S,W,N,E 相反。
