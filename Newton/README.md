# Newton · 棱镜投影排程（核心创新前端）

> 「光溯」项目最具差异化的视觉装置：**一束光从右下射入悬空三棱镜，在玻璃内折射后，把一学期的排程"投影"到正对用户的幕墙上。**
> 项目名「光溯」= 光 + 溯源；光电学院；第 18 届光电杯主题「智逐光影，溯梦未来」——光是本项目的原生意象，不是硬贴的概念。

## 二、当前版本（v9）效果与约束

**画面构成（按视觉层级）**

1. **幕墙**（左中，5.5 × 2.9 m，正对用户居中）：上面是被投影的一周/一日排程
2. **三棱镜**（右下前景，浮空）：`transmission 0.72` 深蓝玻璃 + `clearcoat 0.7` + 亮边线（opacity 0.85），内部一条静态白光线
3. **入射光**：从画面右下角光口射入棱镜（细白光 + 小暖光斑 sprite）
4. **投影示意光束**：3 条宽淡光从棱镜三面分别射向地面左 / 中 / 右，**全部落在幕布外侧下方**（绝不遮挡课表）
5. **外沿彩色光晕**：幕布框外 4 个柔光 Sprite（贴在幕布后被本体遮挡 → 只在边缘渗出）
6. **静态尘埃**：140 个 Points（位置不更新 → 静止，只作空气感，不飘落）

**v9 硬性约束（后续修改请守住）**

- 棱镜本体必须始终清晰可见、边缘高光明确，不能被光效遮挡
- 光束**不得穿过幕墙前方**、不得遮挡课表画面
- 光束是"投影光路示意"，主要停留在幕墙外侧 / 下方 / 画面边缘
- 幕墙排程**不被逐行照射**，而是整体受彩色投影光笼罩
- 课程表画面必须稳定、清晰、完整，模块边界整齐，文字和网格可读
- **不加**呼吸灯、光束摆动、粒子飘落或任何多余动态
- 保留：真实玻璃折射感、棱镜边缘反光、空气尘埃、微弱体积光
- 整体克制自然，像**高精度光学演示**中的投影模拟，而非科幻激光特效

## 三、交互

| 操作 | 效果 |
|---|---|
| **拖拽画面** | 旋转 / 俯仰棱镜（松手后按新姿态重排光路） |
| **点「切换排程」** | 棱镜转一圈 + 幕布"光流"扫入新版；光束颜色与外沿光晕随新版本模块色同步 |
| 鼠标移动 | 相机轻微视差（唯一的动态，营造光学演示的观察感） |
| 滑块 | 束宽 / 光束亮度 / 幕布辉光 / 曝光 |

## 四、参考来源（不重复造轮子）

- **光照 rig 来源**：<https://github.com/jinruozai/HTML-Light-Demo>（Three.js 物理聚光 + radial-gradient glow sprite + Lathe 灯罩）
  - 核心依赖 `three-html-render`（189★）是 HTML-in-Canvas 的 polyfill
  - 我们的做法：只借鉴其**光源质感**（penumbra 极柔 + 径向 glow），场景按我们自己构图重做
- **玻璃拟态参考**：`liquidGL`（857★，`npm i liquid-gl`，真 WebGL 折射）/ `liquid-glass-paralax`（17★，单文件零依赖）
- **色散/棱镜**：无成熟库，自写 shader（多波长分折射率累加）
- `WICG/html-in-canvas`（3980★）是 **W3C 提案**，需 Chromium flag，**不能用于生产**
