## 1. 风格定版与理由

### 1.1 为什么骨架不动

顶栏标签页式已适配手机、5 个 tab 数量合适、改 App.tsx 外壳会牵动 6 处跳转与 e2e 路径。
换骨架的收益（信息架构更清晰）远小于风险，本期不做。侧边栏式留待功能超过 6 个入口时再议。

### 1.2 扁平 2.0 在本项目的具体含义

现状已经是扁平派，本方案是**精修**，四个动作：

1. **阴影做减法**：卡片阴影从「一层大软影」改为「一层贴地小影」，层次感改由描边承担——这是扁平 2.0 与旧扁平的核心区别（更利落，不靠雾糊糊的投影撑体积）。
2. **深色面保持唯一强调手段**：`.hero-surface` 不动结构，只换暖端光晕颜色（见批次 B 彩蛋 ①）。
3. **间距放大呼吸感**：只做总览页（批次 C），全站铺开风险大。
4. **状态色对齐 Ant Design 语义**：现有 ok/warn/danger 三色已够用，不新增语义，只把「校历/重要日」域划给上理红（见 1.3）。

**明确不做**：玻璃拟态、新拟态、暗色模式、粗野主义——信息密度高的排程/课表界面用了会更糊（指南第 ⑥ 章结论，本方案采纳）。

### 1.3 上理红与光谱叙事的关系（本方案的设计核心）

产品叫「光溯 / LightPath」，光谱叙事是识别度本体：冷端靛蓝（操作与选中）+ 暖端琥珀（节奏与点缀）。
**上理红不进光谱主叙事**，它的位置是——

> **「校」域专属语义色**：校庆、重要日、120 周年、页脚校训。
> 红色在中文校园语境里恰好就是「重要 / 喜庆 / 截止」的颜色，语义自洽，不是硬贴。

边界规则（防止红与靛蓝打架）：
- 上理红**只出现小面积**（圆点、描边、≤0.16 透明度的光晕、11px 小字），不与 brand 靛蓝大面积相邻；
- 页面底色光晕（`index.css` body 的琥珀径向光晕）**保持琥珀不动**——页面底是产品语言，学校红只出现在「校」相关的面上；
- `.hero-surface-flat`（短宽条）**保持纯冷端**——现有注释已说明暖光晕在矮条上会摊成脏褐色，这条经验同样适用于红。

## 2. 硬验收标准（「好看且实用」的落地形态）

每个批次收尾逐条打勾，任一不满足不提交：

- [ ] **对比度不降**：全部文字/底色组合维持 WCAG AA（≥4.5:1），实测值见 §4.3；
- [ ] **测试全绿**：`npm run typecheck` 0 错 + `npm run test:ui` fail=0 + 离线 e2e 77 断言通过；
- [ ] **信息密度不降**：改前/改后同屏截图对比，不因留白牺牲一屏内可见信息（尤其总览页 Bento 化后）；
- [ ] **彩蛋克制**：全站 ≤ 6 处、全部装饰性、拔掉任何一个都不影响功能理解。

## 3. 彩蛋设计原则与约束

### 3.1 三条军规

1. **彩蛋只做装饰，不承载信息。** 用户不看懂彩蛋，也能正常用完所有功能。
2. **不进 e2e 断言串。** 彩蛋文案必须先过 §3.2 的锁死清单。
3. **只用已核实的事实。** 允许用：1906 年建校（沪江大学源头）、校训「信义勤爱，思学志远」、120 周年（2026）、军工路校区、「上理红」校色。**不用**未核实的细节（具体食堂名、楼名、日期），宁可少不要错。

### 3.2 e2e 锁死文案清单（实测自 `scripts/e2e-sched-session.mjs`，一律不改）

```
你的节奏，已经有了轮廓 / 掐指一算 / 可以用分号一起答 / 先把刚才的事定完 /
草稿待确认 / 连着两轮没对上 / 好，先不排了 / 好几件事 / 挪哪个 / 候选是这些 /
把这段时间空出来 / 这段时间空出来了 / 记下了 / 还没写进日程 / 写进 /
校园资料服务暂时未连接
```

执行批次 B 前需重读该脚本全文确认清单没有增补；凡断言命中的串及其所在句子，一律绕开。
（同理 `tests/` 下各单测若有 UI 文案断言，改前先 grep。）

### 3.3 彩蛋总清单（6 处，按批次排布）

| # | 位置 | 做什么 | 批次 |

| ① | `.hero-surface` 暖端光晕 | 琥珀 → 上理红（藏在深色面底色里的校色，首屏/今日卡/画像/题卡 4 处自动生效） | A |
| ② | 校历「校庆」事件圆点 | 紫 → 上理红，图例自动跟随（`chartColors.ts` 一处改动） | B |

| ④ | 页脚 | 校名年份行下方加校训小字「信义勤爱 · 思学志远」（`App.tsx:409` 附近） | B |

## 4. 批次 A：令牌与组件类（L1+L2，只动 2 个文件）

> `tailwind.config.js` + `src/index.css`。零 `.tsx` 改动，typecheck 必绿，测试理论上零影响。
> 深色面光晕虽属彩蛋①，但它是纯 CSS，放本批一起提交。

### 4.1 `tailwind.config.js` 变更表

| 令牌 | 现值 | 新值 | 说明 |
|---|---|---|---|
| `school.red` | —（新增） | `#9E1B32` | 上理红参考值（深绯红）。白底 7.9:1、paper 底 7.4:1，作小字也达标。**顶部注释须写明：参考值，待与官方 VI 手册核对** |
| `school.light` | —（新增） | `#FBEDEE` | 上理红浅底（校庆徽标底、标签底）。对 `school.red` 文字 6.9:1，对 `ink` 文字 13.7:1 |
| 其余全部令牌 | — | **不动** | ink / paper / brand / accent / ok / warn / danger / chart 全部保持。最小 diff，光谱叙事不折腾 |

注意：`school.*` **不进 `chart.*` 数据色组**，避免破坏 `chartColors.ts` 头注释「两边必须同步」的既有契约。

### 4.2 `src/index.css` 变更表

| 类 | 现值 | 新值 | 理由 |
|---|---|---|---|
| `.panel` 阴影 | `shadow-[0_8px_28px_rgba(22,35,63,0.06)]` | `shadow-[0_1px_2px_rgba(22,35,63,0.04),0_8px_24px_rgba(22,35,63,0.05)]` | 贴地小影 + 大软影减淡，扁平 2.0 的利落感 |
| `.panel` 描边 | `border-ink/[0.07]` | `border-ink/[0.09]` | 阴影变轻后由描边补层次（仍在"几乎不可见但托得住"区间） |
| `.hero-surface` 暖端 | `rgba(217,131,36,0.19)` | `rgba(158,27,50,0.15)` | **彩蛋①**。透明度略降：红比琥珀显眼，压一档才"藏在底色里" |
| `.button-primary` 阴影 | `0_6px_16px_rgba(43,76,155,0.22)` | `0_2px_8px_rgba(43,76,155,0.16)` | 与 .panel 同思路，按钮更贴面 |
| `.hero-surface-flat` | — | **不动** | 短条只取冷端的既有裁决保持 |
| body 背景光晕 | 琥珀 0.09 | **不动** | 页面底是产品语言（§1.3 边界规则） |

### 4.3 对比度实测表（2026-10-06 用 WCAG 相对亮度公式实算）

| 组合 | 比值 | 判定 |
|---|---|---|
| `school.red #9E1B32` 对 白 | 7.90:1 | ✅ AA（余量大） |
| `school.red` 对 `paper #F6F7FA` | 7.38:1 | ✅ AA |
| `school.red` 对 `school.light #FBEDEE` | 6.94:1 | ✅ AA |
| `ink` 对 `school.light` | 13.70:1 | ✅ AAA |
| `brand #2B4C9B` 承白字（现状对照） | 8.05:1 | ✅ 不变 |
| `ink-faint #66708A` 对 paper（现状对照） | 4.6:1 | ⚠️ 无余量，**本期不动它，也不在它上面叠新色** |

## 6. 批次 C：总览页 Bento 局部（最后做，前置条件：A/B 已验收）

> 唯一动 `.tsx` 布局的批次。范围**只有总览页**：`OverviewPage.tsx` + `TodayCard.tsx` / `WeekStrip.tsx` / `DeadlineBoard.tsx` 的外层网格。

- 网格重排为便当格：**今日卡 = 大格（2×2）· 七天条 = 宽格（2×1）· 节点倒计时 = 竖格（1×2）· 校历 = 可展开格（1×1）**；窄屏回落单列（现有响应式行为保持）。
- 间距：卡片间 `gap-3 → gap-4`，卡内 `p-4 → p-5`（仅总览页，验收"呼吸感提升但今日卡课程列表不被挤出首屏"）。
- 硬约束：**所有 `data-testid`、条件渲染、事件处理一律不动**，只动 className 与网格结构；动手前跑 `node scripts/capability_map.mjs` 确认总览页守护测试名单，改完跑对应测试。
- 周计划页 / 梨宝页 **本期不碰**（重灾区留待下期，避免一次改版引入过多变量）。

## 7. 每批次的标准流程（对齐 AGENTS.md §〇）

```bash
node scripts/preflight.mjs --allow-dirty   # ① 开工
# ……改动……
npm run typecheck                           # ② 秒级
npm run test:ui                             # ③ UI 全量
node scripts/impact.mjs                     # ④ 自证没打断旧功能
npm run e2e                                 # ⑤ 必须离线模式（关后端）
node scripts/capability_map.mjs --check     # ⑥ 守护映射没过期
git commit -m "feat(ui): …"                 # ⑦ 一批一 commit，只提交不 push
```

批次 A 不触及任何 `.tsx`，④⑥ 预期直接 PASS；批次 C 必须全跑。

## 8. 回滚

- 每批次一个独立 commit：不满意 `git revert <commit>` 即可，无数据、无契约、无 golden 影响。
- 批次 A 的令牌是全站生效点，回滚它即可整体回到改前观感——这也是把彩蛋①（纯 CSS）放进 A 的原因。

## 9. 待核对项（诚实清单）

1. **上理红官方色值**：`#9E1B32` 为深绯红参考值（本文实测对比度达标）。官方《标准色与辅助色（正式版）》可在 [校徽视觉形象页](https://xb.usst.edu.cn) 下载 VI 手册核对；若官方值对比度 <4.5:1，则文字场景用加深版、装饰场景（光晕/圆点）用官方原值。网络检索到的 CMYK 参考约 C40 M100 Y50 K20，换算后偏绛紫，与"深绯红"直觉有出入，**以 VI 手册为准**。
   - 来源：[上理视觉形象资源页](https://xb.usst.edu.cn)、[沪 31 所高校校徽标准色报道（上观新闻）](https://sghexport.shobserver.com)
2. **校训写法**：「信义勤爱，思学志远」——上墙前再对一次官方页脚/校门刻字写法。
3. **e2e 锁死清单**：执行批次 B 前以 `scripts/e2e-sched-session.mjs` 当日全文为准，本文 §3.2 是 2026-10-06 快照。

## 10. 本期明确不做（防蔓延）

暗色模式 · 骨架变更 · 玻璃/新拟态 · 移动端 `m.html` 换肤（只做主色不冲突的目视检查）· 周计划页与梨宝页精修 · 任何「其他做法」级交互改动（合并 tab、移云同步入口等，全部留 backlog）· Slider/EmptyState 两个零引用组件的去留（白天人工决定）。
