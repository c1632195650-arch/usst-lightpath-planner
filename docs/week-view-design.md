# 周视图设计规范 · week-view-design

> 来源：MOSS《知识融合与周视图交互升级通宵包（E 批·全量）》§2（2026-09-28）。
> 落盘批次：E0（授权范围仅限本文档与索引；实现批次 E4/E5 待 CY 逐项授权后启动，见 BLOCKERS.md）。

## 1. 三条原则

1. **视觉重心唯一**：周视图里**时间轴是主角**，其他一切都是它的注脚。任何新增元素若抢走时间轴的视觉权重，一律砍。
2. **信息按需分层（L0/L1/L2）**：
   - **L0（默认屏上）**：`emoji` + 时间区间 + 地点（简写）；可含一个**通勤分钟徽章**。
   - **L1（hover / focus / 长按）**：一行 `reason`（"为什么排在这"）。
   - **L2（点击卡片）**：详情面板——块内容、**来源**（`source`/`fromEventId`）、**历史变动**（锁定/涟漪记录）、可执行动作。
3. **动效节制**：只允许 `opacity` / `transform` 过渡；时长对齐 UI v2 动效令牌四档（`tailwind.config.js transitionDuration`：instant 90ms / fast 140ms / base 220ms / slow 360ms，2026-10-07 批次 A 落地；本文原「120–200ms」区间由 fast 档承接），`prefers-reduced-motion` 下全部关闭。**禁止**弹跳、禁止超过 slow 档（360ms）的入场；悬停/按压反馈用 fast/instant 档。

## 2. 落地令牌（复用现有 `tailwind.config.js`，不新造色）

| 用途 | 令牌 | 依据 |
|---|---|---|
| 页面/卡片底 | `paper` / `paper-card` / `paper-sunken` | `tailwind.config.js:20-24`（已含 WCAG 对比度实测注释） |
| 主文字/次级/标签 | `ink` / `ink-soft` / `ink-faint` | 同上（4.5:1 以上） |
| 选中/操作 | `brand` / `brand-dark` / `brand-light` | 同上 |

| 块类别色 | `chart.{violet,indigo,cyan,green,amber,coral,slate}` | 语义映射集中在 `src/constants/chartColors.ts`，**不许各处硬编码 hex** |
| 圆角 | `rounded-card`（16px） | `tailwind.config.js:58` |

## 3. 三处"字太多"的具体处置（可量化）

- 块卡片内**中文字符数上限**：浏览态 ≤ 14 字（地点+动作），超出以 L2 详情承载；
- 一周视图默认屏上**不再出现** `reason` 长句、不再出现引擎 issue 明细（收进顶部一条聚合提示条，点击展开）；
- 顶部信息条与工具栏**合并为一行**，滚动时吸顶。

## 4. 渐进式披露与交互（E5 对应条款）

- 详情抽屉用**原生 `<dialog>` + CSS transition**（零新依赖），自带 focus trap、Esc 关闭、`::backdrop`；
- 抽屉手势：**内容滚到顶才响应下拖关闭**（对齐 vaul 的工程细节），避免滚动与拖拽冲突；
- 浏览态**不渲染**任何编辑控件；编辑态把分散的块内按钮合并为一个动作条（锁定 / 换地点 / 挪时间 / 删除 / 说明来源）；
- 抽屉必须 100% 键盘可达（`aria-modal` 正确、焦点回到触发块）。

## 5. 诚实原则（贯穿呈现层）

- 通勤分钟来自 `TimeBlock.transfer.minutes`：`reliable === false`（估算）时显示 `≈` 前缀；
- 任何画像驱动的偏好呈现，必须带"这是我猜的，可改"口径（L3 边界，`project-core.md` §4）。

## 6. 验收门槛（E4/E5 DoD 引用）

1. 1280×800 与 390×844 两档下，时间轴高度占内容区 ≥60%；
2. 浏览态单块中文字符数中位数 ≤14；
3. 既有 ui/E2E 用例全绿且新增用例数 > 0；axe-core 通过；
4. 浏览态可点击元素数**减少**，每块操作距离（点击次数）**不增加**；
5. 回退开关 `WEEK_VIEW_V3=false` 走旧渲染路径。
