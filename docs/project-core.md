## 0. 一页话

- **一句话**：一个足够懂上理、足够懂你、也知道自己**分寸**的智能伙伴。
- **它回答的不是**「你今天几点该干什么」，**而是**「**在上理，这件事究竟该怎么做**」。
- **核心角色**：梨宝。**形态**：网页 / PWA，一套代码覆盖双端。
- **数据地基**：520 篇上理官方文档（515 篇入全文检索）+ 147 个校园地点 + 1600 余节点路网。

## 1. 先把「留白率」的去向说死

留白率是**初版构想**的核心主张（原话：考试周留白率不降反升，22% → 30%）。
**它已撤出核心位置。** 这不是"暂时不做"，是定位层面的否决。

撤出的三条理由：

1. 它是**设计者的价值观**（"你该多休息"），不是用户提出的需求；
2. 它**不可验证**——没有任何数据能证明"留白 30% 的用户更满意"；
3. 它**可被替代**——真正让人感到"被理解"的，是安排会随情况变，而不是一个固定比例。

**它现在的身份**：排程引擎目标函数里**若干软权重中的一项**（`blankDeficit`）——可调、可关、**不进验收标准**、**不进对外材料的主叙事**。

> 一句话：**从「卖点」降为「参数」。**

**执行要求**：任何对外材料（申报书 / PPT / 演示视频 / 答辩口述）不得再把留白率当作核心卖点或记忆点。

## 2. 三次转向（为什么最终不是排程工具）

| 版本 | 定位 | 为什么变 |
|---|---|---|
| v1 | 反内卷排程工具（纯前端） | 把排程当主干，用留白对抗内卷 |
| v2 | 梨宝校园 AI 助手（加后端 + RAG） | 「贴心」本质是伙伴而非工具；规则引擎撑不起"该科研还是比赛"这类判断 |
| **v3（当前）** | **懂上理的智能决策伙伴** | 排程与留白都只是一种视角、一种输出形式，不该喧宾夺主 |

## 4. 设计红线：智能边界四层

**梨宝可以递地图、陪走一段、指方向，但方向盘永远在用户手里。**

| 层 | 内容 | 我们怎么做 |
|---|---|---|
| **L1 信息层** | 客观事实（保研看绩点 / 排名；光电杯 9/28 截止） | 直接给，引来源 |
| **L2 引导层** | 结构化路径（打比赛有哪些节点、各何时开始） | 给时间线，帮他看清路 |
| **L3 建议层** | 画像驱动的倾向（你高数偏弱 + 想保研 → 先稳绩点） | 给倾向 + **讲理由** + 留余地 |
| **L4 决策层** | 最终决定（"你今天别打球去刷题"） | **绝不做**，只给选项与后果 |

派生三条产品规则：

1. **L3 以上必须能一键推翻**——每个建议都可撤销；
2. **不确定必须标注**——宁可说"我不知道"，也不悄悄猜；
3. **任何新功能先问一句：它落在哪一层？** 越界即砍。

## 5. 能力地图：什么是灵魂，什么是输出

- **灵魂** = 三钩子 + 智能边界。
- **能力**（服务于灵魂的手段）：

| 能力 | 服务哪一层 |
|---|---|
| 上理知识问答（RAG） | L1 |
| 场景引导（比赛节点 / 保研时间轴 / 社团实况） | L2 |
| 画像驱动的建议 | L3 |
| 校园空间（跨校区转场、就近推荐） | L2 / L3 |
| **排程** | **L3 的一种输出形式**（不是主干） |

### 5.1 排程的当前目标：不是"排得好看"，是**像人一样安排**

1. **记得你确认过的**——你点头的安排被钉住（`lockLevel`），其余绕开它排；
2. **知道来不及了**——越接近截止，优先级自动上抬，必要时主动腾时间；
3. **注意得到你累不累**——上周高强度，这周目标自动下调一档（跨周负荷）；
4. **改动只影响该改的地方**——加一件事，不重排整周（增量滚动）；
5. **诚实**——不确定的数据明确标出，不按"刚好来得及"硬排。

> 留白率属于这里的**软目标之一**，与上述五条并列，**不享有特殊地位**。

## 7. 明确不做

- 不替用户做最终决定
- 不对迷茫的新生强行排日程（该给的是探索清单）
- 不接管教务系统、不改课表（冲突只提示）
- 不做"给你 3～4 个版本挑一个"（一版为主 + 单块可换）
- 不做社交 / 搭子 / 组队
- 不做"AI 直接把整周排好、说不出为什么"
- 不做道德判断（不出现"拖延 / 效率低 / 落后"）
- 光感知硬件暂缓（失败不影响主线）

## 9. 记忆点（2026-09-15 定稿）

原记忆点（留白率）作废。**主记忆点已定为「懂分寸」**：

> **主记忆点 =「懂分寸」**——一个会给你地图、陪你走、给你方向，但**绝不替你拍板**的 AI 伙伴。

理由：

1. 多数 AI 助手在两个极端——要么什么都答不了，要么直接替你做主；**"知道什么时候不该替你决定"真正稀缺**；
2. 它可以被演示——信息不足时如实说"我不确定"，比任何特效有说服力；
3. 它同时解释了留白率为何该移出核心——**替你规定"你该多休息"，本身就是一种越界**。

**答辩口径**（三分钟内怎么讲）：

> 所有时间管理工具都在替你决定该做什么。我们做了一个**会拒绝替你决定**的助手——
> 它给你地图、陪你走、给你方向，但方向盘永远在你手里。**这恰恰是多数 AI 助手缺失的那一步。**

**落选备选**（保留记录，不再作为主记忆点）：排程侧的「像人一样安排」——更直观，但通用产品也能做到，差异化弱于「懂分寸」。

> 状态：✅ **已定稿**（2026-09-15，CY 拍板）。与 §3 三钩子中的「懂分寸」同源，切勿改成两套说法。
