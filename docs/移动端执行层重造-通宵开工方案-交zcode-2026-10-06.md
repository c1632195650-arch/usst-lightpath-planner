### 1.1 背景一句话

**产品定位已翻转**：网页端负责「想清楚」，手机端负责「**做出来**」。当前手机端是「网页端的搬运工」——所有日程块等大平铺、没有时间感、没有待办、没有陪伴。本批把它重造成**执行层的仪器**。

### 1.2 CY 的原话（验收唯一标准）

> "手机app的定位是从各方面提升用户在通过上理生活助手制定计划过后要能切实的方便的执行！"

> "要能上下滑动查看**仅仅一天的日程**……**非常醒目的事件时间地点（要有时间燃烧条，可以根据比例标记还有多就事件结束）**"

### 1.4 时间燃烧条规格

```
progress = (nowMin - startMin) / (endMin - startMin)，钳制 [0,1]
显示：进度条 + 百分比 + 「还剩 N 分钟」
颜色：<33% 绿 · 33-66% 琥珀 · >66% 红
相位：未开始(nowMin<startMin) → 「还有 N 分钟开始」progress 0
      进行中 → 正常计算
      已结束(nowMin≥endMin) → 返回 null（该块已从当前块排除）
```

**必须抽成纯函数** `burnRatio(startMin, endMin, nowMin) → {ratio, remainMin, phase}`，放 `lib/` 并单测（**三相位必测**）。
