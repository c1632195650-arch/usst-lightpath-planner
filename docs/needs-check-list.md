## 一、合规边界（先说清楚）

高德数据**只用于两件事**：
1. **校准步行分钟数**（把 est 换成实测值，`verified` 改 true，note 标「高德实测」）
2. **验证建筑归属**（判断某楼在 516 还是 334）

**不做的**：不把经纬度坐标写进 `campus_map.json`。
图谱继续只存「相对位置 + 步行分钟 + 邻近地标」——这是原有的合规设计（规避地图测绘风险），保持不破。
