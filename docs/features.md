## M2 · 课表导入【人 B】

- **输入**：教务 **PDF 导出（主）** / 粘贴文本 / CSV / 手动录入
- **输出**：`Schedule` → `patch({ schedule })`
- **文件**：`src/features/schedule/`、`src/lib/parseSchedule.ts`（含 PDF 解析）
- **含**：PDF 解析（`pdfjs-dist`，前端本地解析）+ 粘贴/CSV 通道、周次解析（`1-16` / `1,3,5` / 单双周）、地点→校区推断
- **状态**：⬜
- **约束**：**严禁涉及教务账号密码**（PDF 也只在浏览器本地解析、不上传）；解析失败必须能退回手动录入；卡住超过 1.5 天就先做手动；**D3 前取 1–3 份真实 PDF 课表样本校准**

## M4 · 日排程引擎【B 算法 / A UI】⚠️ 高耦合

- **输入**：`Schedule` + `UserProfile` + `Task[]` + `weekNo`
- **输出**：`WeekPlan`
- **文件**：`src/lib/planner/scheduler.ts`（B）、`src/features/plan/`（A）
- **含**：贪心填充、疲劳惩罚（同科超 2h → ×0.6）、强制留白、跨校区转场缓冲、留白滑块、"今天不想动"重排
- **状态**：⬜
- **约束**：**先写 `scheduler.test.ts` 用固定输入断言输出**，再写 UI。这是唯一两人高耦合模块，用测试避免甩锅

**算法要点**（详见作战手册 §7）
```
可用时间 = 清醒时长 − 课程 − 三餐 − 跨校区转场
可分配给任务的部分 = 可用时间 × (1 − 留白率)
30 分钟为一槽，按优先级贪心填充
连续 2 个深度块后强制插 15–30 分钟休息
剩余未填槽标记为 'blank'，不要填满
```
