# 报告三 · 框架之外的更宏大的发展方向评估

> 生成：2026-10-24（zcode）。姊妹篇：报告一（重构偿债）、报告二（新功能菜单）。
> **回答的问题**：把"可移植校园助手框架"抽出去之后，这条路再往前走，还有哪些更大的落脚点？哪些是真机会、哪些是听起来高级的坑？
> **评估口径**：每个方向按「是什么 / 为什么是现在 / 我们手里的牌 / 怎么起步 / 风险与反面 / 量级判断」六段讲，尽量说人话。最后给三条推荐主线和归位表（归上理线 / 归框架线 / 待定）。

## H1 Agent 化与 MCP 化——从"回答者"到"代办者"（推荐主线一）

**是什么**：现在用户问光溯"光电杯什么时候截止"，它回答；未来的形态是用户说"帮我盯着光电杯"，它**办事**——查到截止日期、在日历上建提醒、考前一周自动在周计划里腾出准备时间。行业语言：从 chatbot（回答者）到 agent（代办者+协同者）。[中国教育科研网 2026-03 的评论](https://www.cernet.edu.cn/xxh/yc/202603/t20260304_2720453.shtml)把这列为高校信息化最该补的课，且建议"小步快跑"而非大一统平台——正是我们的路线。

**为什么是现在**：2026 年是 MCP（Model Context Protocol，让 AI 应用互相调用的开放标准）从实验走向企业级的转折年——2024-11 发布后增速是所有 AI 协议里最快的，2026-07 发布新版规范，生态正收敛为"MCP（工具/数据接入）+ A2A（智能体互相协作）"双标准（[增长统计](https://nevermined.ai/blog/model-context-protocol-adoption-statistics)、[2026-07-28 规范](https://blog.modelcontextprotocol.io/posts/2026-07-28)、[企业级采用分析](https://www.cdata.com/blog/2026-year-enterprise-ready-mcp-adoption)、[MCP+A2A 治理](https://airia.com/blog/ai-agent-interoperability-what-mcp-and-a2a-mean-for-enterprise-governance)）。**早期接入者定义接口，后来者只能跟随。**

**我们手里的牌（为什么顺）**：光溯的三个核心能力——排程、四库检索、地点/路网——**本来就长着"工具"的形状**：输入明确、输出结构化、无副作用边界清楚（引擎是纯函数！）。把 `/api/plan/understand`、`buildWeekPlan`、`/api/poi` 包成 MCP server，任何 AI 客户端（别人的智能体、IDE、语音助手）就都能"调用光溯排个课表"。这意味着**光溯从"一个 App"升维成"一套别人系统里的能力"**——分发问题（App 没人装）被绕过。

**怎么起步（小步快跑版）**：① 上理线先做"半代办"：对话里识别多步意图（"帮我盯住光电杯"→建 deadline→设提醒→排准备块，逐步放权，每步确认）；② 框架线 M5 后把三个能力包成 MCP server（工具清单：`search_campus_kb` / `plan_week` / `find_place`）；③ 对外发一篇《把校园助手做成 MCP 工具》——这本身就是社区传播点。
**风险与反面**：agent 自主行动与"智能边界 L4 不做"的张力——解法是**权限分级**（只读查询全自动，改动日历/计划必须逐步确认）；MCP 标准仍在演进，接口层要做薄、可替换。
**量级**：⭐⭐⭐⭐⭐（技术顺、叙事强、正踩潮；比 H2 便宜，比 H4 现实）。

## H2 群体智能数据飞轮——一人用是助手，一校人用是雷达（推荐主线二）

**是什么**：现在每个用户的执行数据只服务自己。若匿名聚合：周三晚图书馆自习块扎堆→"今晚图书馆大概率满，给你备选了教学楼 201"；期末周全院 deadline 热力图→"你们专业这周有三个大作业，要不要提前动手"。**单点数据变群体洞察**，这是官方校园平台（全校通用问答）结构上做不了的——他们没有个体执行数据。

**为什么值得**：这是光溯**最深的一条护城河**（别人要么没数据、要么没画像），也是"留白/节奏"理念从个人升到群体的自然延伸。
**风险与反面（为什么是慢工）**：与"零上报、本地优先"的隐私主张**正面冲突**。做的前提：① 显式 opt-in（默认关，明示聚合了什么）；② 只上聚合统计（k-匿名，人数阈值以下不出数）；③ 隐私政策与 PIA 先行（已在 B 线窗口 B）。冷启动鸡生蛋：人少先聚不出东西，所以排主线二而非主线一。
**怎么起步**：先做"不需要用户数据"的版本——用**引擎的计划数据**（而非执行数据）做群体洞察的 demo（"这个专业第 X 周普遍排了多少复习块"），加上 opt-in 开关埋点，等真实用户起来再开聚合。
**量级**：⭐⭐⭐⭐（差异化最大，隐私设计与冷启动成本也最大）。

## H3 评测基准学术化——把"考卷"本身变成成果（推荐主线三）

**是什么**：你们手里有全国罕见的资产：**100 条对话排程意图金标**（双通道 F1/EM）、**126 条方法库金标**（召回/MRR/拒答/伪科学拦截）、golden 快照基准、带 RV 纪律的测试方法论。把它整理成公开发布的《校园场景 LLM 意图理解与排程评测基准》（数据集+评测脚本+排行榜形态），任何做校园 AI 的团队都能拿去测自己的系统。
**为什么值得**：成本几乎为零（资产现成，只差整理与脱敏复核）；站位极高——**出题人比答题人高一个生态位**；同时是大挑学术作品、论文、4C/大创赛"社会价值"维度的硬材料；社区团队引用你的基准=反向给光溯背书。
**怎么起步**：① 脱敏复核金标（无上理专有信息）；② 写技术报告（构造方法/指标/基线成绩——你们自己的双通道成绩就是第一个榜）；③ 框架线 evals 包发布时一并挂出。
**风险**：低（最大风险是版权与专有信息，复核可解）。**量级**：⭐⭐⭐⭐⭐（性价比之王）。

## H4 开放技能生态——"校园版应用商店"（先占叙事，别先动工）

**是什么**：社团、图书馆、后勤在光溯上自建"技能"（查实验室开放、社团活动报名、报修进度），光溯成为校园服务的统一入口底座。
**为什么排后**：治理复杂度（技能审核/安全/质量）远超 1 人团队；且没有 H1 的工具化打底，插件接口无从谈起。**但叙事现在就可以占**——比赛材料里一句"框架 + 技能市场架构预留"即可。等 campuskit 社区有第一批外部贡献者后再评估。
**量级**：⭐⭐⭐（方向对，时机未到）。

## H5 学习分析与教育测量（待落地后）

五维执行力评估若积累真实学期数据，可与学校教育学/心理学方向合作研究（学习行为与执行模式）——这是"从工具到研究平台"的跳跃，也是与学工部合作的深化抓手。**前提：真实规模用户 + 伦理审查**。量级：⭐⭐⭐。

## H6 校园空间智能 / 数字孪生（备选）

路网+POI 已是雏形。纯软件可做的：无障碍路线（坡道/电梯图层）、安静度/拥挤度人工标注图层（数据从 H2 来）；硬件版（光传感器阵列）历史上暂缓过——维持暂缓，除非与后勤/实验室共建。量级：⭐⭐。

## H7 多模态交互（窄场景先行）

拍海报→提取截止日→一键建 deadline：识别场景窄（文字+日期）、价值直接；整课表 OCR 不做（PDF 链路已够）。挂在报告二 D2 下按需立项。量级：⭐⭐。

## H8 校际开发者联盟（框架线的自然延伸）

campuskit 开源后，"接入你的学校"的贡献者群体=潜在的组织化社区（DanXi 用学生公益组织维持一校六年是正面样本；WakeUp 开源仓被收购后删库是反面教材）。远期形态：高校开发者联盟/暑期贡献计划/以 campuskit 为载体的学生开发基础设施叙事——这会把项目从"一个比赛作品"变成"一个社区的品牌"。**归框架线，M5 后自然生长，不提前规划。** 量级：⭐⭐⭐⭐（长期）。

## H9 商业化深水区（只观察，不动手）

现实门槛：B2B 卖学校需要公司主体+招投标资质+驻场服务；面向学生的 C 端市场历史上一律打不过免费+官方。唯一被验证的变现路径是"引擎资产被收购"（Reclaim 模式）——而那要求引擎先在真实市场里被用起来。**结论：三年内不投入任何商业化动作，全部价值先以比赛/软著/落地/开源声誉存储。**量级：⭐（现在）。

## H10 反向国际化（待定彩蛋）

海外高校普遍开放课程/校园 API（Cornell/Harvard 公开课程数据接口），框架的"档案接入"模式在数据开放环境里**落地成本反而更低**；留学生场景（中文母语+海外校园）是天然种子用户。语言与合规是门槛。**不动手，但写进框架仓 README 的 vision 一句话。**量级：⭐⭐。

## 三条推荐主线（如果只能选三条）

1. **主线一（下一跳）：Agent 化/MCP 化**——上理线做"半代办对话"，框架线把能力包成标准工具。技术最顺（能力本来就工具形）、叙事最强（2026 主轴）、分发问题被绕开（不用求人装 App）。**先做 H3 配套**：评测基准先发，让"我们的 agent 能力可被第三方验证"。
2. **主线二（最深护城河，慢工）：群体智能飞轮**——先 opt-in 埋点与聚合 demo，等真实用户。与隐私主张的张力用"默认关+聚合阈值+PIA"三件套解。
3. **主线三（性价比之王，随时可做）：评测基准学术化**——几乎零成本，占住"出题人"生态位，直接反哺三大赛事与论文。

**三者关系**：H3 给 H1 背书（可验证），H1 给 H2 导流（agent 触达多→用户多→数据多），H2 沉淀的数据又让 H1 更聪明——**这是一条能自我强化的链，而不是三个孤立方向。**

## 风险总提醒

所有宏大方向的共同陷阱：**在主战场（比赛+落地）未站稳前分兵**。本报告全部方向都设计成"可挂在既有里程碑上的一小步"，没有任何一条需要你现在投入超过 2 个半天——除了主线一，它值得进入 2027 年的正式排期。
