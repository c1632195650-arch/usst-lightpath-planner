06客户端 0.4.10

  • 为什么必须重出：APK 是包内资源模式，页面离线可用，但 API 地址编译在 JS 里。旧包只认 101.35.253.143。
  • 怎么重出：以线上 0.4.9 的 dist-mobile 为基线，只替换共享 chunk 里的 IP 常量，并清理 38 个无引用的旧哈希产物；业务代码与 0.4.9 完全一致（刻意不把 10-11 未部署改动带进客户端）。
  • 产物：dist/apk/lightpath-0.4.10.apk，9.1 MB，versionCode 16。
  • 签名：SHA-256 7b742acd6c54664812a83b9f1c62df7fa2ce1d91ee481bfa3b5c15942e656568，与 0.4.9 同一证书 → 可覆盖安装，App 数据保留。
  • 分发：http://43.142.141.186/apk/lightpath-0.4.10.apk。10-25 前旧包可通过应用内「检查更新」拿到它。

五个踩过的坑

  1. 模型缓存在 ~/.workbuddy/cache/fastembed，不是 /opt/usst/app/model_cache。丢了它又开着 HF_HUB_OFFLINE=1，/api/search 直接 500。
  2. server/requirements.txt 不含 pdfplumber，但课表解析依赖它；重建 venv 必须显式装。
  3. data/ 要整目录同步；只传 usst_articles.db 会报 campus_vocab.json 缺失。
  4. systemd 的 LIBAO_CORS_ORIGINS 必须含新 IP，否则网页能开、接口全被 CORS 拦。
  5. caddy 原本占 80（Hermes 入口），已 disable --now，别启回来。
